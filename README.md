## 6. 트러블슈팅 (Troubleshooting)

### 6-1. 문제 1
- 증상:레이아웃 오버플로우
- 원인: flex: wrap 미지정
- 해결: flex: wrap 등 사용
- 회고: 컨텐츠의 양이 늘어나거나 해상도가 변할 때 요소들이 어떻게 흐르는지에 대해 경험

### 6-2. 문제 2
- 증상:충돌,깃허브
- 원인:잘못된 터미널 명령어 사용
- 해결:최신 코드를 안전하게 내려받은 후 병합하는 정석적 입력으로
- 회고:터미널 명령어를 실행하기 전 현재브렌치 위치와 로컬 동기화 상태를 체크하는 습관이 중요함을 깨달았으며
- 모호한 깃 명령어 사용 대신 안전한 브렌치 이동이 중요함을 아는 계기가됨
